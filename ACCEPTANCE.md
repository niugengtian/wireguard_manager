# 验收状态 / Acceptance status

状态仅使用 `READY`、`BLOCKED`、`NOT VERIFIED` 和 `VERIFIED`。
Status vocabulary is limited to `READY`, `BLOCKED`, `NOT VERIFIED`, and `VERIFIED`.

| 验收项 / Gate | 状态 / Status | 证据 / Evidence |
| --- | --- | --- |
| 管理员创建 quota=2 用户 / Admin creates quota-2 user | VERIFIED | 自动化集成测试 / automated integration test |
| 前两台设备成功、第三台被拒绝 / First and second devices succeed; third denied | VERIFIED | 自动化集成测试 / automated integration test |
| 配置一次性交付，私钥不进入数据库、数据文件或日志 / One-time config; no private key at rest or in logs | VERIFIED | 自动化集成测试 / automated integration test |
| Reset 撤销旧公钥、生成新密钥并保留 IP / Reset revokes old key, generates a new key, preserves IP | VERIFIED | 集成测试与期望状态断言 / integration test and expected-state assertion |
| Delete 移除 Peer 并立即释放地址 / Delete removes peer and releases address | VERIFIED | 集成测试与地址复用断言 / integration test and address-reuse assertion |
| 并发创建获得不同 IP / Concurrent creates receive different IPs | VERIFIED | 双线程集成测试与数据库唯一约束 / two-thread test and database uniqueness constraint |
| 对象级授权和上传 RBAC / Object authorization and upload RBAC | VERIFIED | 集成测试返回 404/403 / integration test returns 404/403 |
| 安装包上传/下载 SHA-256 一致 / Installer upload/download SHA-256 matches | VERIFIED | 使用运行时生成字节的集成测试 / integration test with runtime-generated bytes |
| CSRF 与持久登录限速 / CSRF and persistent login limiting | VERIFIED | 自动化集成测试 / automated integration test |
| 本地 CLI 设备生命周期与 `0600` 配置文件 / Local CLI lifecycle and `0600` config file | VERIFIED | CLI 集成测试 / CLI integration test |
| Python 依赖漏洞审计 / Python dependency vulnerability audit | VERIFIED | `pip-audit`：无已知漏洞；`cryptography` 固定为 48.0.1 或更高 / no known vulnerabilities |
| 真实浏览器用户流程 / Real browser user flow | VERIFIED | 管理员创建 quota=2 用户；用户下载首份配置、显示第二台二维码、看到第三台被拒绝；reset 保留 IP 且代次变为 2；delete 后地址可复用；浏览器错误日志为空 / full in-app browser flow, empty browser error log |
| 中英双语 README、页面与 CLI help / Bilingual README, pages, and CLI help | VERIFIED | 真实浏览器检查 `/login`、`/help`、`/admin`；CLI help 自动化断言 / browser checks and CLI assertions |
| 真实 `wg` / `syncconf` / Live `wg` / `syncconf` | NOT VERIFIED | 等待明确批准，功能有意禁用 / intentionally disabled pending explicit approval |
| AWS 部署与资源 / AWS deployment/resources | NOT VERIFIED | 明确不在范围内，未执行任何 AWS 操作 / out of scope; no AWS action performed |

浏览器验收使用隔离临时数据目录与仅监听回环地址的 Waitress 进程。验收后已停止进程并删除临时数据库、会话密钥和期望状态文件；测试数据不可恢复，且不含用户生产数据。
The browser run used an isolated temporary data directory and a loopback-only Waitress process. The process was stopped and the temporary database/session secret/desired-state files were deleted after verification; the test data is not recoverable and contained no user production data.
