# 验收状态 / Acceptance status

状态仅使用 `READY`、`BLOCKED`、`NOT VERIFIED` 和 `VERIFIED`。
Status vocabulary is limited to `READY`, `BLOCKED`, `NOT VERIFIED`, and `VERIFIED`.

浏览器验收使用隔离临时数据目录、文件适配器与仅监听回环地址的 Waitress 进程。验收后已停止进程并删除临时数据库、会话密钥和期望状态文件；测试数据不可恢复，且不含用户生产数据。
The browser run used an isolated temporary data directory and a loopback-only Waitress process. The process was stopped and the temporary database/session secret/desired-state files were deleted after verification; the test data is not recoverable and contained no user production data.
